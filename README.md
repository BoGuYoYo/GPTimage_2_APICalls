<h2>OpenAiGPT_image2 API 使用说明</h2>
<br>src 目录包含一个 Jakarta Web + Electron 的图片生成应用源码，支持：</br>
<br></br>
<br>文生图：POST /v1/images/generations</br>
<br>图像编辑（图生图）：POST /v1/images/edits</br>
<br>参考图变体：POST /v1/images/variations</br>
<br>多图结果预览与单张下载</br>
<br></br>
<br>无需部署，下载即可使用</br>
<br>支持官方API和中转站API</br>
